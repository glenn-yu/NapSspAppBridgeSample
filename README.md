# nap ssp Native SDK 샘플

이 레포는 Android와 iOS에서 nap ssp 광고를 붙이는 방법을 **처음 보는 사람도 따라할 수 있게** 보여주는 샘플이다.

## 이 레포에서 할 수 있는 것

- Android 샘플 보기
- iOS 샘플 보기
- WebView 하이브리드 연결 보기
- 포맷별 광고 연결 자리 확인하기

## 처음 읽을 순서

1. `docs/start-here.md`
2. `docs/quickstart.md`
3. `docs/install.md`
