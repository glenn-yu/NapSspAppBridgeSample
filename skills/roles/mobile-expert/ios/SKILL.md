# Mobile Expert — iOS Skill

Purpose
- Provide templates and automation for iOS mobile engineering: xcframework management, SPM vs vendored, build & CI, simulator smoke tests, and release guidance.

Features
- xcframework handling checklist, vendoring policy, and LFS guidance
- xcodebuild commands and simulator smoke scripts
- PR review checklist and code comment style for Swift

Usage
- Run handler.sh for generation or to run simulator smoke steps.
