# Mobile Expert — Android Skill

Purpose
- Provide checklists, templates, and automation for Android mobile engineering tasks: SDK integration (ads), build & CI, runtime smoke tests, code style, and release guidance.

Features
- Integration checklist for ad SDKs (banner, native, rewarded, interstitial, video)
- Build & CI checklist and example workflow snippets
- Runtime smoke test scripts and adb commands
- Code comment and PR review guidelines specific to Android

Usage
- See handler.sh for commands: generate templates, run smoke tests, create PRs.
