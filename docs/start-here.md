# 시작하기

이 문서만 먼저 보면 된다.

## 무엇을 하는 샘플인가

- Android / iOS에서 nap ssp 광고를 붙이는 예시
- 일반 광고와 WebView 하이브리드 광고를 둘 다 보여줌
- 실제 SDK를 넣을 위치를 보여줌
- SDK가 아직 없으면 폴백 화면과 상태 메시지가 보임
- 광고가 안 뜨면 SDK가 아직 연결되지 않은 것이다

## 처음 할 일

1. 앱 실행
2. 포맷 하나 선택
3. `광고 띄우기` 또는 WebView 버튼 누르기
