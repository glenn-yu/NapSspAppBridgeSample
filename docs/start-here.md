# 시작하기

이 문서만 먼저 보면 된다.

## 이 샘플이 하는 일

- Android와 iOS에서 nap ssp 광고를 붙이는 방법을 보여준다
- 일반 광고와 WebView 하이브리드 광고를 둘 다 보여준다
- 실제 SDK를 꽂을 자리와 버튼 흐름을 같이 보여준다

## 먼저 할 일

1. `quickstart.md` 보기
2. 앱 실행하기
3. 포맷 하나 고르기
4. `광고 띄우기` 또는 하이브리드 `init`/`load...` 버튼 눌러보기

## 초보자에게 중요한 것

- 처음엔 `banner`나 `hybridWebView`부터 보면 된다
- 광고가 안 뜨더라도 폴백 화면과 상태 메시지를 보면 된다
- 문서가 많아 보여도, 실제로는 이 문서 → quickstart → 앱 실행 순서면 된다
