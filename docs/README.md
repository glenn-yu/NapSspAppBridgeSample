# 문서 안내

이 레포를 처음 보는 사람은 아래 순서만 따라가면 된다.

## 처음 읽을 순서

1. `quickstart.md` — 5분 안에 전체 흐름 보기
2. `install.md` — 필요한 앱과 계정/환경 확인
3. `setup.md` — 레포에서 어디를 보면 되는지 확인
4. `format-matrix.md` — 어떤 포맷을 언제 쓰는지 보기
5. `hybrid-webview.md` — 웹뷰에서 SDK를 부르는 법 보기
6. `android-formats.md` / `ios-formats.md` — 플랫폼별 예시 보기
7. `build-test.md` — 빌드 확인 방법 보기
8. `troubleshooting.md` — 막혔을 때 보기

## 한 줄 설명

- `quickstart.md`는 시작점
- `install.md`는 준비물
- `setup.md`는 레포 구조 안내
- `format-matrix.md`는 포맷 선택표
- `hybrid-webview.md`는 하이브리드 샘플 설명
- `troubleshooting.md`는 문제 해결

## 참고

이 샘플은 Android와 iOS에서 실제 SDK를 꽂을 위치와 WebView 브리지 구조를 보여준다.
실제 SDK 버전과 의존성은 파트너 가이드 값에 맞춰 넣는다.
