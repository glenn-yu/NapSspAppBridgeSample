# 설치

이 문서는 필요한 준비물만 적는다.

## Android 준비물

- Android Studio 또는 Gradle
- JDK
- Android SDK
- nap ssp Android SDK 의존성
  - `io.github.nasmedia-tech:admixer-ssp:1.0.21`
  - `com.google.android.gms:play-services-ads-identifier:18.3.0`

## iOS 준비물

- Xcode
- iOS 빌드 환경
- SPM 또는 CocoaPods 중 하나
- nap ssp iOS SDK 패키지
  - `https://github.com/Nasmedia-Tech/iOS-SSP-Mediation-SPM.git`
  - `https://github.com/Nasmedia-Tech/iOS-SSP-SPM.git`

## 준비되면 확인할 것

- 미디어 키가 있는가
- 광고 단위 ID가 있는가
- 문서 버전과 가이드 버전이 같은가
