# 문제 해결

## WebView가 안 열릴 때

- 네트워크가 되는지 확인한다.
- URL이 맞는지 확인한다.
- Android는 인터넷 권한이 있는지 본다.
- iOS는 App Transport Security 설정을 본다.

## 메시지가 안 오갈 때

- 웹에서 보내는 브리지 이름이 맞는지 확인한다.
- 네이티브에서 받는 핸들러 이름이 맞는지 확인한다.
- 웹 함수 이름이 정확한지 확인한다.
- 콘솔 로그를 먼저 본다.

## 빌드가 안 될 때

- JDK / Xcode / 시뮬레이터 환경을 먼저 확인한다.
- 프로젝트 파일이 실제로 있는지 확인한다.
- 예시 코드가 프로젝트 구조와 맞는지 확인한다.
