# QA Memory - Safari/WebKit Browser 확장

작성: 2026-05-18 KST

## 배경

- OpenClaw memory 검색이 `Copilot token exchange failed: HTTP 403`으로 실패했습니다.
- 사용자 지시에 따라 이번 작업의 연결 메모리는 프로젝트 문서에 자체 보관합니다.

## 이번 작업 범위

Safari/WebKit 계열에서 하이브리드 브릿지 샘플이 깨지지 않는지 확인하는 정적/브라우저 레벨 QA를 추가했습니다.

### 변경 파일

- `ios/Sources/NapSspIOSSample/index.html`
  - `</body>` 뒤에 Cleanup 카드가 놓여 있던 HTML 구조를 수정했습니다.
  - Cleanup 카드를 본문 내부로 이동했습니다.
  - iOS 샘플에도 Custom AdUnit 입력을 추가해 Android 샘플과 QA 흐름을 맞췄습니다.
  - `window.webkit.messageHandlers.NapSspBridge` 접근 전 `messageHandlers` 존재 여부를 확인하도록 방어했습니다.
  - Native 응답 파싱 실패 시 throw 대신 `Raw response` 로그를 남기도록 보강했습니다.
  - 로그 출력에 `escapeHtml`을 적용해 SDK/detail 문자열이 HTML로 해석되지 않게 했습니다.

- `scripts/browser_webkit_qa.mjs`
  - WebKit/Safari 브라우저 QA용 Node 정적 테스트를 추가했습니다.
  - 검증 항목:
    - 주요 HTML 샘플의 `<body>`/`</body>`/`</html>` 구조
    - `</body>` 뒤 잔여 콘텐츠 없음
    - init/load/clear 및 전체 광고 포맷 QA 버튼 존재
    - standalone Safari 환경에서 bridge 없음이 throw 없이 false/warn 처리
    - WKWebView mock에서 `postMessage` payload가 JSON string으로 전달됨
    - Native → JS 응답 파싱, 이벤트 파싱, malformed response 방어

## 검증 결과

실행 명령:

```bash
node scripts/browser_webkit_qa.mjs
```

결과:

```text
browser-webkit-qa: PASS
```
