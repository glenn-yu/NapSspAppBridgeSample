## 먼저 확인할 것

- Android Studio 또는 Xcode가 있는가
- JDK / Android SDK 또는 iOS 빌드 환경이 있는가
- 미디어 키와 광고 단위 ID를 받았는가

## 이 레포의 역할

이 샘플은 광고 코드를 어디에 넣는지 보여준다.
실제 SDK가 들어오면 광고가 뜨고, 없으면 폴백 화면이 보인다.
