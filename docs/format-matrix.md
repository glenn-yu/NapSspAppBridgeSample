# 포맷별 적용표

이 문서는 nap ssp 문서에서 나온 포맷들을 **WebView 앱에 어떻게 붙일지** 한 번에 보는 표다.

## 먼저 결론

- **배너**: 화면 아래 고정처럼 쓰기 좋다
- **네이티브**: 앱 UI 안에 카드처럼 섞기 좋다
- **동영상**: 화면 안에 재생 영역을 만들기 좋다
- **리워드 동영상**: 유저가 끝까지 보면 보상을 주는 흐름에 맞다
- **전면 동영상**: 페이지 전환 전 / 작업 완료 후 보여주기 좋다

## Android / iOS 공통 구조

1. 웹에서 `AppBridge.postMessage(...)`로 요청한다
2. 네이티브가 요청을 받는다
3. 네이티브가 광고 포맷을 띄운다
4. 광고 이벤트를 다시 웹에 보낸다
5. 웹은 상태 표시나 다음 동작을 처리한다

## 어떤 포맷을 언제 쓰는지

| 포맷 | 추천 위치 | 특징 |
|---|---|---|
| 배너 | 화면 하단 고정 | 가장 단순하고 안전함 |
| 네이티브 | 콘텐츠 사이 | UI에 자연스럽게 섞임 |
| 동영상 | 상세 화면 안 | 재생 영역이 필요함 |
| 리워드 동영상 | 보상 버튼 뒤 | 시청 완료 보상 흐름 |
| 전면 동영상 | 화면 전환 시 | 강한 주의 집중이 필요할 때 |

## 샘플의 목표

이 샘플은 실제 광고 SDK를 전부 붙이기 전에,
**웹 ↔ 네이티브 브리지 흐름**과 **포맷별 화면 배치**를 먼저 익히기 위한 것이다.
