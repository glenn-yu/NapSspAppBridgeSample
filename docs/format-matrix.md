# 포맷별 적용표

이 문서는 nap ssp 가이드에서 나온 포맷을 **Android와 iOS 앱에 어떻게 붙일지** 한 번에 보는 표다.

## 먼저 결론

- **배너**: 화면 아래 고정
- **네이티브**: 카드처럼 콘텐츠 사이에 삽입
- **동영상**: 앱 안 재생 영역에 노출
- **리워드 동영상**: 시청 완료 후 보상 지급
- **전면 동영상**: 화면 전환 전 전체 화면 노출

## 공통 흐름

1. 앱이 광고를 요청한다
2. SDK가 광고를 로드한다
3. 광고 뷰를 화면에 붙인다
4. 이벤트를 받는다
5. 종료 시 리소스를 정리한다

## 어떤 포맷을 언제 쓰는지

| 포맷 | 추천 위치 | 특징 |
|---|---|---|
| 배너 | 화면 하단 | 가장 단순하고 안전함 |
| 네이티브 | 리스트 / 카드 영역 | UI에 자연스럽게 섞임 |
| 동영상 | 상세 화면 안 | 재생 영역이 필요함 |
| 리워드 동영상 | 보상 버튼 뒤 | 시청 완료 보상 흐름 |
| 전면 동영상 | 전환 직전 / 완료 후 | 전체 화면으로 보여줌 |

## 샘플의 목표

이 샘플은 실제 광고를 붙이기 전에,
**포맷별로 어떤 뷰를 만들고 어디에 연결하는지**를 먼저 익히는 데 초점을 둔다.
